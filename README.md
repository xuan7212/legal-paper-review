# 法学论衡 · 项目说明

面向法学本科生与硕士生的论文初稿自查工具，帮助作者在提交导师前检查论证缺口、推敲表达，并追踪修改后的处理结果。当前版本为 v0.2.0。

## 从这里开始

- **运行与演示** — 打开 [应用工程说明](应用工程/README.md)，按说明启动后，从应用中的“项目说明”和“体验示例演示”开始。
- **了解产品** — 阅读 [产品设计文档](设计资料/产品设计文档.md)，查看用户、场景与功能取舍。
- **了解技术** — 阅读 [技术方案](设计资料/技术方案.md)，查看实现依据与审查流程。
- **查看早期原型** — 打开 [历史 HTML 原型](历史归档/法学论文审查助手-Demo.html)，回顾最初的交互设计。

## 目录入口

```text
法律agent/
├── README.md       项目说明与阅读入口
├── 应用工程/       程序、依赖、配置、测试与运行说明
├── 设计资料/       产品设计文档与技术方案
├── 历史归档/       早期独立 HTML 原型
└── AGENTS.md       项目开发与版本交付约定
```

工程相关命令在“应用工程”目录内执行。从当前目录进入工程可使用 `cd 应用工程`。
